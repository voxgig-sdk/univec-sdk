POST /v1/convert

Operation ID: convertEmbedding.

Authentication: bearer token (bearerAuth).

Request body

application/json

Property Type Required Description
embeddings array of array of number (float) Yes Vectors to translate. Each must match the source model's dimension exactly.
source_model string Yes Model space the supplied vectors are currently in.
target_model string Yes Model space to translate into. A converter must exist for the source/target pair, see listModels.

Example request body:

{
  "embeddings": [
    [
      0.01,
      0.02,
      0.03
    ]
  ],
  "source_model": "alibaba-nlp-gte-large-en-v1.5",
  "target_model": "nomic-embed-text-v1.5"
}

Responses

200: Translated embeddings

application/json

Property Type Required Description

data.embeddings array of array of number (float) Yes Translated vectors, in the target model's dimension.
data.source_model string Yes
data.target_model string Yes
success boolean Yes
