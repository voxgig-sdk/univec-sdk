Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

const { UnivecSDK } = require('@voxgig-sdk/univec-sdk-js')

const client = new UnivecSDK({ apikey: process.env.UNIVEC_APIKEY })

{
  "base": "https://api.univec.ai",
  "auth": {
    "prefix": "Bearer"
